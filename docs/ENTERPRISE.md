# 企业内部审计管理系统企业能力

## 领域覆盖

- **审计宇宙**：维护组织、流程、系统和风险对象
- **风险评估**：评估影响、可能性和控制成熟度
- **年度计划**：编制项目组合、资源与审计委员会计划
- **审计项目**：管理范围、团队、里程碑与沟通
- **审计底稿**：执行程序、取证、复核和归档
- **审计发现**：记录事实、标准、原因、影响和建议
- **整改跟踪**：分派措施、到期提醒和升级
- **整改复核**：验证证据、效果和剩余风险
- **审计报告**：生成项目报告、管理层报告和趋势分析

## 横向控制基线

- ADMIN 与 OPERATOR 权限分离，管理员审批由服务端强制校验；
- 模块白名单、字段约束、唯一编号、乐观锁和合法状态迁移；
- 企业控制项支持组织、期间、责任人、风险、期限和幂等键；
- 经办与复核职责分离，办结前至少登记一份带 SHA-256 的业务凭证；
- 外部系统同步保存成功、失败、回执编号和审计详情；
- 支持组合检索、分页、逾期筛选、CSV 导出、评论与时间线；
- `/api/domain/decision` 对企业内部审计管理系统关键场景返回决策、0–100评分、计算指标和处置动作；
- prod profile 对默认账号密码、数据库口令和不安全跨域来源执行启动门禁。

## 生产适配

真实 `GRC`、IAM、消息、对象存储和第三方供应商接口只预留集成边界，由部署企业自行配置。生产上线前必须完成权限矩阵、数据映射、容量压测、灾备演练、安全评估与用户验收。
